# 短期上昇株ハンター v3

## v3の変更
- 監視銘柄の手入力を廃止
- JPX公式の東証上場銘柄一覧から対象銘柄を自動取得
- 銘柄コード＋銘柄名を表示
- 各銘柄にYahoo!ファイナンスのチャートリンク
- UIを日本語化
- A/B/C/Dの説明とランキングロジックをアプリ内に表示
- Aの損切りを一律-2%から「75日線を再度明確に割る水準」へ変更
- Aの買いトリガーは75日線＋2ティックを初期設定
- 全銘柄をA/B/Dでスキャンし、上位候補だけCを確認

## 戦略
A: 75日線押し目
B: ブレイクアウト
C: 決算モメンタム
D: モメンタム＋押し目

総合スコアは A30% / B25% / C20% / D25% に、複数戦略該当の加点を加えます。

## 注意
CはYahoo Financeで取得できる四半期財務による暫定ロジックで、市場予想との差は含みません。
呼値単位は銘柄・価格帯で異なるため、実注文時は証券会社画面で確認してください。
