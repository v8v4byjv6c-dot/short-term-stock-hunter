# 短期上昇株ハンター v5

## v5 修正点

### A｜75日線押し目
参考書の考え方に合わせてA候補を厳格化しました。

A候補になる絶対条件:
- 75日移動平均線が上向き
- **現在の株価が75日線より下**
- 75日線から下に離れすぎていない
- 75日線とのマイナス乖離が小さいほど高評価

つまり、75日線より上にいる銘柄はA候補に入りません。
候補になった後、75日線を上抜ける価格を「買い価格目安」として表示します。
買った後は、75日線を再び明確に割る水準を初期損切り目安にします。

### B｜ブレイクアウト
ブレイク後にすでに上がりすぎている銘柄を減点するようにしました。

ブレイク水準から:
- +3%超: 軽く減点
- +5%超: 減点
- +7%超: 大きく減点
- +10%超: 強く減点

これにより「ブレイクしたから何でも高評価」ではなく、
まだ追いかけ買いしやすい位置にいる銘柄を上位にしやすくします。
