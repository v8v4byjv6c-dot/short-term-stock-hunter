# 短期上昇株ハンター v6

## v6の追加
各銘柄について「なぜこの評価なのか」をアプリ内で確認できるようにしました。

- A: 75日線の上向き度、75日線とのマイナス乖離率
- B: ブレイクした高値、ブレイク水準からの上昇率、出来高倍率、20日騰落率
- B過熱度:
  - 0〜3%: 🟢 ブレイク直後
  - 3〜7%: 🟡 やや上昇済み
  - 7%超: 🔴 上がりすぎ注意
- C: 営業利益・売上高の前年同期比
- D: 60日騰落率と押し目からの反発
- CSVにも評価理由を追加

v5で修正したAの「75日線より下だけを候補にする」条件と、
Bの「ブレイク後に上がりすぎた銘柄を減点」ロジックは維持しています。
