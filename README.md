# 短期上昇株ハンター v7

日本株の短期上昇候補を、A〜Dの複数戦略で自動スクリーニングするStreamlitアプリです。

## 現在の基本思想

### A｜75日線押し目
参考にした書籍の考え方を中心にしたメイン戦略です。

- 75日移動平均線が上向き
- 現在株価は75日線より下
- 75日線から下に離れすぎていない
- マイナス乖離が小さいほど高評価
- 75日線を上抜ける水準を買いトリガー
- 買った後に75日線を再度明確に割る水準を初期損切り目安

### B｜ブレイクアウト
- 75日線が上向き
- 過去一定期間の高値を更新
- 出来高増加
- ブレイク後に上がりすぎた銘柄は減点
- 0〜3%: ブレイク直後
- 3〜7%: やや上昇済み
- 7%超: 上がりすぎ注意
- 初期損切り参考値は「ブレイク水準 − 1ATR(14)」

### C｜決算モメンタム
Yahoo Financeから取得可能な四半期財務を使う暫定ロジックです。
営業利益前年同期比+20%以上を中心に評価します。
市場予想コンセンサスとの差は現在含みません。

### D｜モメンタム＋押し目
直近60日で強く上昇した銘柄が、一度調整した後に短期反発している状態を評価します。

## 総合ランキング
A 30% / B 25% / C 20% / D 25% を基本に、複数戦略への同時該当を加点します。

## 楽天証券向け注文表示
v7から、候補銘柄ごとに楽天証券で入力する形に近い注文参考値を表示します。

A/B/D:
- 買い：逆指値
- 「株価が○円以上になったら、○円の指値を発注」

A:
- 約定後の損切り：75日線を再び明確に割る参考価格以下で逆指値売り → 成行

B:
- 約定後の損切り：ブレイク水準−1ATR(14)以下で逆指値売り → 成行

注意:
- アプリから楽天証券へ自動発注する機能ではありません。
- 逆指値の指値注文は急騰時に約定しない可能性があります。
- 損切り成行はギャップダウン等で想定より低い価格で約定する可能性があります。
- 呼値、値幅制限、注文市場、SOR/PTS等は実際の注文画面で確認してください。

# 改訂履歴

## v1｜初期版
短期で上昇しそうな日本株を機械的に探すためのプロトタイプを作成。
ユーザーの基本方針である「75日線が上向いている銘柄の押し目」を中心に開始。

## v2｜戦略の拡張
Aだけでは候補が限定されるため、異なる短期上昇パターンを比較できるようA/B/C/Dの考え方を導入。

A: 75日線押し目  
B: ブレイクアウト  
C: 決算モメンタム  
D: モメンタム＋押し目

## v3｜自動スクリーニング化
手入力の監視銘柄方式から、プログラム側が対象銘柄を取得してランキングする方式へ変更。

主な変更:
- JPX上場銘柄一覧から対象を自動取得
- 銘柄コード＋銘柄名
- Yahoo!ファイナンスのチャートリンク
- 日本語UI
- A/B/C/Dの説明
- 買い価格目安
- Aの初期損切りを一律-2%ではなく75日線基準へ変更

理由:
銘柄を人間が先に選ぶのではなく、条件に合う銘柄をアプリ側で発見することが目的になったため。

## v4｜市場別スキャン
全市場だけでなく、以下を個別にスキャンできるよう変更。

- プライム
- スタンダード
- グロース
- TOKYO PRO
- 全市場

理由:
全銘柄取得には時間がかかり、特に重要視するプライムだけを高速に確認したいという要望のため。
プライムをデフォルトに設定。

## v5｜Aロジック修正・B過熱減点
### A修正
以前のAは75日線から-5%〜+2%を候補にしていたため、75日線より上の銘柄までAに入っていました。

参考書の考え方に合わせ、
「現在株価が75日線より下」
を絶対条件に修正。

理由:
Aは「75日線下から接近し、上抜けを待つ」戦略だからです。

### B修正
ブレイクアウト後に大きく急騰済みの銘柄を高評価しすぎないよう減点を導入。

理由:
ブレイクアウトはポピュラーなモメンタム戦略ですが、高値掴み・ダマシのリスクがあるため。

## v6｜評価理由の可視化
ランキングの点数だけでは「なぜこの銘柄が高評価なのか」が分かりにくかったため、評価理由を表示。

A:
- 75日線の傾き
- 75日線との乖離

B:
- ブレイク水準
- ブレイク後の上昇率
- 出来高倍率
- 20日騰落率
- 過熱度

C:
- 営業利益前年同期比
- 売上高前年同期比

D:
- 60日騰落率
- 押し目からの反発

## v7｜楽天証券注文参考値
候補を見つけた後に「楽天証券の注文画面で何を入力するのか」まで分かるよう拡張。

追加:
- 買い逆指値の条件価格
- 条件到達後の指値価格
- Aの約定後損切り逆指値
- Bの約定後損切り逆指値
- BのATR(14)
- CSVにも注文参考値を出力

理由:
スクリーニングから実際の注文判断までの距離を短くするため。

# データと注意事項
株価・財務データはYahoo Finance等から取得するため、遅延、欠損、取得制限が発生する場合があります。
本アプリはスクリーニング・判断補助ツールであり、将来の株価上昇や約定を保証しません。
