## 📘 本ベース A/B/C/D
これまでv1〜v9で育てたロジックです。

### A｜75日線押し目
- 75日線が上向き
- 現在株価は75日線より下
- 75日線とのマイナス乖離が小さいほど高評価
- 75日線上抜けを買いトリガー
- 再び75日線を明確に割る水準を初期損切り目安

### B｜ブレイクアウト
- 高値更新
- 出来高増
- 75日線上向き
- ブレイク後の上がりすぎを減点
- 75日線からの大幅上方乖離も減点
- ATR(14)を損切り参考に使用

### C｜決算モメンタム
Yahoo Financeで取得できる四半期財務を使う暫定ロジック。

### D｜モメンタム＋押し目
強く上昇した銘柄が一度調整し、再上昇する形を評価。

## 🧪 AI式・独自統合スクリーナー
「本のロジックを一度忘れて、短期上昇候補を独自に作るなら」という考えで追加した別モードです。

### 6要素
- トレンド: 25%
- 需給・出来高: 20%
- モメンタム: 15%
- 業績: 15%
- エントリー位置: 15%
- リスク・過熱: 10%

### 2つの重要スコア
**上昇力**
トレンド・出来高・モメンタム・業績を中心に「銘柄自体の強さ」を評価。

**今の買いやすさ**
エントリー位置と過熱・ATR等を中心に「今から入っても無理がないか」を評価。

強い株でも高値圏に走りすぎていれば、
「上昇力は高いが買いやすさは低い」
と分離します。

### セットアップ自動分類
- 🎯 押し目・75日線接近
- 🔥 ブレイク準備中
- 🚀 ブレイク直後
- 💹 決算加速
- 📈 モメンタム継続
- 監視

特に「ブレイクした後」だけではなく、
**高値の直前まで来て値動き・出来高が整っている『ブレイク準備中』**を探せるようにしたのが特徴です。
