# 短期上昇株ハンター v8

日本株の短期上昇候補を、A〜Dの複数戦略で自動スクリーニングするStreamlitアプリです。

## v8の主な追加

### ロジック総合診断
外部AI APIを使わず、追加料金なしで各銘柄にコメントを付ける機能を追加しました。

判定例:
- 🟢 条件良好
- 🟢 有力候補
- 🟡 慎重に検討
- 🔴 追いかけ注意
- ⚪ 様子見

コメントでは以下を自動評価します。

A:
- 75日線の上向き度
- 75日線とのマイナス乖離
- 買いトリガーへの近さ
- 初期損切り幅

B:
- ブレイク直後か
- ブレイク後に上がりすぎていないか
- 出来高倍率
- ATR基準の損切り幅

C:
- 営業利益・売上高の前年同期比

D:
- 60日モメンタム
- 押し目からの再上昇

最後に「方針」を表示します。
例:
- 買い逆指値の条件到達を待つ
- 注文条件を確認して候補に残す
- 高値追いは避け、押し待ちを優先
- チャート確認後に判断

このコメントは生成AIではなく、数値ルールによる文章化です。
同じ入力なら同じ判断になるため、投資ルールの一貫性を保ちやすいのが特徴です。

# 現在の基本思想

## A｜75日線押し目
メイン戦略。

- 75日移動平均線が上向き
- 現在株価は75日線より下
- 75日線から下に離れすぎていない
- マイナス乖離が小さいほど高評価
- 75日線を上抜ける水準を買いトリガー
- 買った後に75日線を再度明確に割る水準を初期損切り目安

## B｜ブレイクアウト
- 75日線が上向き
- 過去一定期間の高値を更新
- 出来高増加
- ブレイク後の上がりすぎを減点
- 初期損切り参考値はブレイク水準−1ATR(14)

## C｜決算モメンタム
Yahoo Financeで取得可能な四半期財務を使う暫定ロジック。
営業利益前年同期比+20%以上を中心に評価。
市場予想コンセンサスとの差は現在含みません。

## D｜モメンタム＋押し目
直近60日で強く上昇した銘柄が、一度調整した後に短期反発している状態を評価。

## 総合ランキング
A 30% / B 25% / C 20% / D 25% を基本に、複数戦略への同時該当を加点。

# 楽天証券向け注文表示
v7から、候補銘柄ごとに楽天証券で入力する形に近い注文参考値を表示。

- A/B/D: 買い逆指値
- A: 75日線基準の初期損切り
- B: ブレイク水準−1ATR(14)基準の初期損切り

アプリからの自動発注は行いません。

# 改訂履歴

## v1｜初期版
75日線が上向いている銘柄の押し目を探すプロトタイプを作成。

## v2｜戦略拡張
A/B/C/Dの4戦略を導入。

A: 75日線押し目  
B: ブレイクアウト  
C: 決算モメンタム  
D: モメンタム＋押し目

理由:
1つの戦略だけでなく、異なる短期上昇パターンを比較するため。

## v3｜自動スクリーニング
監視銘柄の手入力を廃止し、JPX上場銘柄一覧から対象を自動取得。
銘柄名、Yahoo!ファイナンスチャートリンク、日本語UIを追加。

理由:
人が候補を選ぶのではなく、アプリ自身が候補を発見するため。

## v4｜市場別スキャン
プライム / スタンダード / グロース / TOKYO PRO / 全市場を選択可能に。
プライムをデフォルトに設定。

理由:
全市場スキャンの時間を短縮し、重要視するプライムを素早く確認するため。

## v5｜Aロジック修正・B過熱減点
Aを「現在株価が75日線より下」に限定。
Bはブレイク後の上がりすぎを減点。

理由:
Aを参考書の考え方に忠実にし、Bの高値掴みリスクを抑えるため。

## v6｜評価理由の可視化
各銘柄について「なぜこの評価なのか」を表示。
Bにはブレイク水準・出来高倍率・過熱度などを追加。

理由:
ランキング点数だけでは売買判断の根拠が分かりにくかったため。

## v7｜楽天証券注文参考値
候補銘柄について、楽天証券の逆指値画面に入力する形に近い参考値を表示。
BにATR(14)基準の初期損切りを追加。

理由:
候補発見から実際の注文判断までの距離を短くするため。

## v8｜ロジック総合診断
外部AI APIを使わず、A〜Dの数値をルールベースで文章化。
「条件良好」「慎重」「追いかけ注意」などを自動表示。

理由:
追加料金なしで、ChatGPTのような「数字を読んだコメント」に近い補助を実現するため。
また、生成AIよりも判断基準を固定しやすく、バックテスト・改善につなげやすいため。

# 注意
本アプリはスクリーニング・判断補助ツールです。
株価・財務データには遅延、欠損、取得制限があり得ます。
将来の値上がりや約定を保証しません。
