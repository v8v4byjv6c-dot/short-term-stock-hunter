# 短期上昇株ハンター v4

## v4の主な追加
- 市場別スキャンボタン
  - プライム（デフォルト・推奨）
  - スタンダード
  - グロース
  - TOKYO PRO
  - 全市場（プライム＋スタンダード＋グロース）
- 選択した市場の銘柄だけ株価を取得するので、プライム等の単独スキャンは全市場より処理量を削減
- 選択市場と対象銘柄数を画面表示
- 同じ市場を再スキャンするボタン
- v3の機能（A/B/C/D、買い価格、A損切り、銘柄名、Yahooチャートリンク、日本語UI）を維持

## TOKYO PROについて
JPXのメイン上場銘柄ExcelにTOKYO PROが含まれる場合はそこから抽出し、
見つからない場合はJPXのTOKYO PRO Marketページを補助的に読み取ります。
Yahoo Financeで価格データを取得できないTOKYO PRO銘柄はランキングから自動的に外れます。
